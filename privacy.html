Privacy Policy

Last updated November 14, 2026

This policy explains what this website and the Votive content tool collect, and what they don't.

This website

  • No accounts, no forms, no cookies, no analytics and no advertising trackers.
  • The page loads a 3D graphics library from jsDelivr, a public content network. Like any web server, it receives your IP address and browser details to deliver the file. See jsDelivr's privacy policy for how it handles that.
  • The site's host may keep standard server logs for security and reliability.

The Votive content tool

The tool connects only to Votive's own TikTok account, using TikTok Login Kit and the Content Posting API. When it's connected, it receives:

  • basic profile information for that account (user.info.basic: an account ID, display name and avatar), used to confirm the right account is connected;
  • permission to upload videos to that account's drafts (video.upload).

The access token is stored only on Votive's own computer. It isn't shared, sold or used for anything else. The tool doesn't access anyone else's TikTok account and collects no data about viewers or customers. Access can be removed at any time in TikTok's settings under Security → Manage app permissions.

Shopping on TikTok Shop

When you buy from Votive on TikTok Shop, TikTok processes your order and personal information under TikTok's own Privacy Policy. Votive receives the order details TikTok shares with sellers to fulfil it, and uses them only for that.

Children

This website and tool aren't directed at children under 13, and we don't knowingly collect their information.
